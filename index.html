About GridAI

What is actually deployed?

GridAI uses seven independently trained forecasting pipelines, each selected by validation MAE from six candidates. Each live model predicts its target from lagged historical values, rolling statistics and calendar features. Multi-step forecasts are recursive: each prediction becomes available history for the next 15-minute step.

  • Electricity Load
  • Wind Generation = onshore + offshore
  • Solar Generation
  • Hydro Generation = run-of-river + water reservoir + pumped storage
  • Chronological 70/15/15 train, validation and test split
  • No future target values are read during live inference
  • Fossil = lignite + coal-derived gas + gas + hard coal + oil; all five must be observed
  • Nuclear = reported nuclear generation, without filling missing periods; historical coverage ends April 2023
  • Imports = generation_import_Import_sum; country flows are not added again
  • Delta predictions are added to the previous MW observation before export, evaluation or display

Future forecast origins have no upper date cutoff; the model recursively bridges from the source history to the selected date. Missing targets are excluded, never interpolated. Evaluation is one-step walk-forward; a small separate three-origin daily recursive backtest is exported for context. Feature bars show validation permutation importance for every selected model.
