About GridAI

What is actually deployed?

GridAI uses four separately trained forecast-safe XGBoost regressors for live inference. Each live model predicts its target from lagged historical values, rolling statistics and calendar features. Multi-step forecasts are recursive: each prediction becomes available history for the next 15-minute step.

  • Electricity Load
  • Wind Generation = onshore + offshore
  • Solar Generation
  • Hydro Generation = run-of-river + water reservoir + pumped storage
  • Chronological 70/15/15 train, validation and test split
  • No future target values are read during live inference
  • Historical notebook comparisons include Persistence, Direct XGBoost and Delta XGBoost

Forecast dates are not capped at the latest source observation. When a requested origin is later than the dataset, the backend recursively bridges from the latest real observation before generating the requested horizon.
